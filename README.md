# 每月營收轉入／轉出 自動分類與交叉分析

> Monthly enrollment revenue classifier: rule-based classification of raw sales exports, with human-in-the-loop flags and automatic cross-checks. Built with Python and Claude Code.

把系統匯出的每月轉入／轉出原始報表，自動判斷每一筆的**業績單位**與**學員來源**，再產出三張交叉分析表並自動勾稽。
這個流程我在工作上每月實際使用，**作業時間由約 8 小時縮短到約 20 分鐘，回測分類準確率約 99%**。

本 repo 為公開版：所有人名、單位、課程與金額都已換成虛構資料，程式邏輯與實際使用的版本相同。

## 要解決的問題

每個月要把 4 張系統匯出的報表（兩個分區 × 轉入／轉出）逐筆標上「單位」和「來源」，才能做營收分析。過去完全手工處理，有三個痛點：

1. **規則多**：同一位學員的來源，要對照名單來源表、上個月的紀錄、退費紀錄，還有合作招生該算哪個單位
2. **人員會調動**：業務換單位後，舊的對照表就錯了
3. **容易默默出錯**：三張分析表各自加總，對不起來也不會有人發現

## 我設計的規則（程式怎麼判斷）

程式碼是我與 Claude Code 協作完成的；以下的判斷規則、優先順序與驗證方式由我依實際業務訂定。

**單位**：依「績效人員」查對照表。對照表會被歷史分類檔自動更新，並以最新月份為準，處理人員調動的問題。

**來源（只有本部自家業務需要判斷）**，依以下優先順序，先命中的優先：

| 順序 | 規則 | 範例資料 |
| --- | --- | --- |
| 1 | 使用者手動指定（`--override`） | 鄭同學 |
| 2 | 同一個月同時出現在轉入與轉出 → 建議「退換」（退費後重報） | 吳同學 |
| 3 | 名單來源表：同月優先，其次最近的前幾個月；同條件下優先已成交 | 王同學、林同學、楊同學 |
| 4 | 沿用該學員上一次的來源 | 黃同學 |
| 5 | 都找不到 → 黃底待填，不猜 | 羅同學 |

**合作招生（聯招）的歸屬**也分層判斷：簡述有寫就照寫，再看聯招單位，最後看聯招人員屬於哪個校園；判斷不出就留黃底請人填。

**交叉分析**：合作招生的金額由雙方各認列一半；規格沒列到的單位不自動歸類，要人工用 `--judge` 指定。

## 怎麼避免 AI 或程式默默出錯

| 設計 | 作用 |
| --- | --- |
| **黃底＝待填** | 新人員、來源判斷不出時不猜，交給人填 |
| **淡橘底＝系統建議** | 程式推論的結果都標色，滑鼠移到儲存格可看判斷依據（例：「名單來源表 10月：聯招／留學部」） |
| **三表金額自動勾稽** | 來源、課程、單位三張表的總金額必須一致，否則報告直接標示「不一致，請檢查」 |
| **淨人數以學員編號去重** | 同一位學員報多門課只算一人，轉出扣回 |
| **分週涵蓋檢查** | 週營收的分週如果漏掉某些日期，程式會警告 |
| **回測**（操作流程） | 用已人工分類的舊月份重跑，比對準確率 |

## 執行方式

需要 Python 3.10 以上。

```bash
pip install -r requirements.txt

# 1. 產生假資料
python3 make_sample_data.py

# 2. 分類：產出分類草稿（黃底待填、橘底建議）
python3 classify.py \
  --raw sample_data/raw_*.xlsx \
  --history sample_data/history_2026.09.xlsx \
  --sources sample_data/sources.xlsx \
  --override 鄭同學=親友 \
  --out output/2026.10_draft.xlsx

# 3. 人工補完黃底後（範例已補好：sample_data/2026.10_classified_sample.xlsx），做交叉分析
python3 analyze.py \
  --input sample_data/2026.10_classified_sample.xlsx \
  --outdir output/analysis --title 2026.10 \
  --judge S015=通路 \
  --weeks 10/01-10/09,10/10-10/16,10/17-10/23,10/24-10/31
```

分類執行結果：

```
完成: output/2026.10_draft.xlsx
新人員: ['新進員']
待填: {('北區轉入', '來源'): 1, ('北區轉入', '單位'): 1, ('南區轉出', '來源'): 1}
```

交叉分析勾稽結果：

```
勾稽 通過 ['402,000', '402,000', '402,000']
```

完整報告範例見 [examples/2026.10_report.md](examples/2026.10_report.md)。

## 檔案說明

| 檔案 | 內容 |
| --- | --- |
| `classify.py` | 第一階段：判斷單位與來源，產出分類草稿與彙總 |
| `analyze.py` | 第二階段：來源分析、課程類別、單位分類三張交叉表，含勾稽與週營收 |
| `make_sample_data.py` | 產生虛構的示範資料，每一筆對應一條規則 |
| `examples/` | 用示範資料跑出的報告 |

## 學到的事

- 規則要先講清楚，例如「人數」是筆數還是學員數，AI 才寫得對
- 日期如果是沒補 0 的純文字（10/5、10/15），用文字比較會默默排錯，要先轉成日期
- 重做舊月份時，只能放該月以前的歷史檔，否則會用到「未來」的資料
